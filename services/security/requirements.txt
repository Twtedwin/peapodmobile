# =============================================================================
# services/security -- fully pinned runtime dependencies
# =============================================================================
#
# PURPOSE
#   A lock-style export of the runtime dependency set declared in
#   `pyproject.toml`, including transitive packages, so that
#
#       pip install -r requirements.txt
#
#   works inside `python:3.12-slim` with no build backend, no resolver
#   backtracking, and no chance of a surprise minor upgrade landing in an image
#   that holds the credential tables.
#
# WHY EXACT PINS (==) AND NOT RANGES
#   Reproducible builds. If two deployments of this service disagree about the
#   version of `cryptography`, they can disagree about which JWTs verify. Pins
#   are the difference between "we know what is running" and "we hope".
#
# HOW TO REGENERATE
#   Edit `pyproject.toml`, then in a clean venv:
#       pip install -e .
#       pip freeze --exclude-editable > requirements.txt
#   and re-apply this header plus the platform marker on uvloop.
#
# DEV/TEST TOOLS
#   Deliberately absent -- see `requirements-dev.txt`. Test frameworks are not
#   installed into the production image.
# =============================================================================
